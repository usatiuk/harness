# Architecture decisions

Decision records preserve significant accepted choices and why they were made.
They complement current design documentation and tests:

- Current documentation describes accepted architecture and behavior.
- A decision record preserves context, considered alternatives, and consequences.
- A research note preserves evidence and uncertainty; it does not become an
  accepted decision automatically.

Use sequential filenames such as `0001-short-title.md`. State the decision's
status and date. Amend a record for clarification, but supersede it with a linked
record when the accepted choice changes materially.

A useful record contains:

- Status and date.
- Context and constraints.
- The accepted decision.
- Alternatives considered and why they were rejected.
- Consequences, risks, and follow-up work.
